# 产品需求文档（PRD）

## 项目概览

> **产品名称：** StoryBoard AI  
> **状态：** 草稿  
> **负责人：** Human PO  
> **最后更新：** 2026-06-12

StoryBoard AI 是一个 Chrome 侧边栏插件，帮助短视频创作者和普通用户把口语化故事描述，自动转换成结构化分镜脚本、AI 视频生成提示词和可选 BGM 提示词。

---

## 问题陈述

AI 视频模型能力很强，但普通用户不会把故事拆成镜头，也不熟悉景别、运镜、画面风格、人物一致性、负面提示词等提示词规范，导致直接生成的视频混乱、不稳定、不可控。

StoryBoard AI 面向短视频创作者、自媒体运营、营销人员，以及想把生日、婚礼、旅行、纪念日等生活故事做成 AI 视频的普通用户，让他们在 Chrome 侧边栏中输入自然语言故事后，快速得到可读、可编辑、可复制、可导出的分镜和提示词。

---

## 目标

- [x] 用户可以在 1 分钟内把一个生活故事或短视频创意输入插件。
- [x] 用户点击生成后，能得到 3-10 个清晰、可读、可编辑的分镜，而不是一大段不可控文本。
- [x] 用户可以直接复制某个镜头提示词，粘贴到即梦、可灵、Sora、Runway 等工具中使用。
- [x] 同一个角色在多个镜头中使用统一外观描述，减少生成视频时人物长相漂移。
- [x] 用户可以局部修改某个镜头，而不用每次重新生成整套内容。
- [x] 用户可以根据整段故事情绪，快速生成一段音乐提示词，用于 AI 音乐工具。
- [x] 用户可以把完整分镜作为项目资产导出保存，方便后续剪辑、复用或继续迭代。

## 非目标

- MVP 阶段不直接调用视频生成 API。
- MVP 阶段不做视频拼接和剪辑。
- MVP 阶段不做首尾帧图片生成。
- MVP 阶段不做团队协作和云端同步。
- MVP 阶段不做账号体系和订阅支付。
- MVP 阶段不做复杂模板市场。

## 用户故事

### EPIC-001：Chrome 侧边栏与基础输入

**STORY-001**  
作为短视频创作者，我希望在 Chrome 侧边栏输入或粘贴一段自然语言故事，以便快速开始把创意转换成分镜。

**验收标准：**
- [ ] Given 用户打开 StoryBoard AI Chrome 侧边栏，When 用户输入或粘贴故事文本，Then 系统应保留文本并展示可生成状态。
- [ ] Given 故事文本为空，When 用户点击生成，Then 系统应阻止提交并提示用户先输入故事。
- [ ] Given 故事文本少于 10 字或超过 5000 字（按去除首尾空白后的 Unicode 码点数计算），When 用户点击生成，Then 系统应阻止提交并给出可理解的校验提示。

### EPIC-002：生成参数与 BYOK 设置

**STORY-002**  
作为免费用户，我希望配置自己的 LLM API Key 和生成参数，以便在不登录、不订阅的情况下生成基础分镜。

**验收标准：**
- [ ] Given 用户未配置 API Key，When 用户点击生成，Then 系统应提示配置 BYOK 后再生成。
- [ ] Given 用户配置 API Key，When 用户保存设置，Then 系统应在本地安全保存该设置并允许后续生成使用。
- [ ] Given 用户打开参数区，When 用户选择目标视频模型、画面风格、画幅比例、单镜头时长偏好和输出语言，Then 系统应把这些参数用于本次生成。

### EPIC-003：AI 分镜与视频提示词生成

**STORY-003**  
作为创作者，我希望系统把故事拆成 3-10 个镜头，并为每个镜头生成完整视频提示词，以便直接复制到 AI 视频工具中使用。

**验收标准：**
- [ ] Given 用户输入有效故事和参数，When 用户点击生成，Then 系统应返回 3-10 个镜头。
- [ ] Given 系统返回镜头，When 用户查看任一镜头，Then 每个镜头应包含概要、景别、运镜、时长建议和完整视频提示词。
- [ ] Given 任意 LLM 生成正在进行，When 用户再次点击分镜或 BGM 生成，Then 系统应通过全局并发锁（并发=1）阻止重复提交并保持加载状态。
- [ ] Given 网络错误、请求超时、429 或 5xx，When 系统调用 LLM 失败，Then 系统应最多自动重试 2 次（合计 3 次尝试）并在耗尽后提示用户。
- [ ] Given 401/403 或 LLM 返回格式异常，When 系统调用或解析失败，Then 系统不应自动重试，应提示生成失败并允许用户手动重试。

### EPIC-004：人物一致性与模板适配

**STORY-004**  
作为普通用户，我希望系统自动识别故事角色并保持角色外观一致，以便多镜头生成时减少人物漂移。

**验收标准：**
- [ ] Given 故事中出现一个或多个角色，When 系统生成分镜，Then 系统应输出角色列表和统一外观描述。
- [ ] Given 某个镜头涉及已识别角色，When 系统生成该镜头提示词，Then 提示词应注入对应角色的统一外观描述。
- [ ] Given 用户选择不同目标模板，When 系统生成提示词，Then 系统应按通用英文电影感模板或即梦/可灵中文模板输出。

### EPIC-005：分镜编辑、复制与导出

**STORY-005**  
作为创作者，我希望查看、编辑、复制和导出分镜，以便把结果保存为项目资产或粘贴到外部工具。

**验收标准：**
- [ ] Given 已生成分镜，When 用户编辑某个镜头的提示词，Then 系统应只更新该镜头内容并保留其他镜头不变。
- [ ] Given 已生成分镜，When 用户点击单个镜头的复制按钮，Then 系统应复制该镜头提示词到剪贴板并给出成功反馈。
- [ ] Given 已生成分镜，When 用户选择 Markdown、JSON 或纯文本导出，Then 系统应生成包含完整分镜和提示词的对应格式内容。

### EPIC-006：BGM 提示词生成

**STORY-006**  
作为创作者，我希望一键生成适配 AI 音乐工具的 BGM 提示词，以便快速得到与故事情绪匹配的配乐方向。

**验收标准：**
- [ ] Given 已输入故事或已生成分镜，When 用户点击生成 BGM 提示词，Then 系统应输出适配 Suno / 海绵音乐等 AI 音乐工具的音乐提示词。
- [ ] Given 用户选择输出语言，When 系统生成 BGM 提示词，Then BGM 提示词应使用用户选择的输出语言。
- [ ] Given BGM 提示词已生成，When 用户点击复制，Then 系统应复制 BGM 提示词到剪贴板并给出成功反馈。
