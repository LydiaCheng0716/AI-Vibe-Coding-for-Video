## 任务描述

实现分镜卡片交互。用户可以查看每个镜头的概要、景别、运镜、时长建议和提示词，手动编辑单个镜头提示词，并复制单个镜头提示词到剪贴板。

---

## 验收标准

- [ ] Given 已生成分镜，When 用户查看结果，Then 系统应按镜头顺序展示分镜卡片。
- [ ] Given 用户打开某个镜头卡片，When 用户查看内容，Then 卡片应展示概要、景别、运镜、时长建议和完整提示词。
- [ ] Given 用户编辑某个镜头提示词，When 用户保存或离开编辑状态，Then 系统应只更新该镜头内容并保留其他镜头不变。
- [ ] Given 已生成分镜，When 用户点击单个镜头复制按钮，Then 系统应复制该镜头提示词到剪贴板并给出成功反馈。
- [ ] Given 剪贴板复制失败，When 用户点击复制，Then 系统应展示失败提示并保留镜头内容。

---

## 技术说明

- 编辑操作应作用于本地当前结果，MVP 不做云端项目保存。
- 复制内容应只包含该镜头可直接粘贴到视频工具的提示词，不默认复制全部分镜。
- UI 应支持 3-10 个镜头的清晰浏览。
