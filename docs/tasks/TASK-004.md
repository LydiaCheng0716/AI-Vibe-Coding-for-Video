## 任务描述

实现视频提示词模板适配能力。MVP 至少支持两类模板：通用英文电影感提示词，以及即梦 / 可灵中文提示词。系统应根据用户选择的目标视频模型和输出语言生成对应风格的镜头提示词。

---

## 验收标准

- [ ] Given 用户选择通用英文电影感模板，When 系统生成镜头提示词，Then 提示词应以英文输出并包含画面主体、动作、景别、运镜、风格、光线和负面提示词信息。
- [ ] Given 用户选择即梦 / 可灵中文模板，When 系统生成镜头提示词，Then 提示词应以中文输出并包含适合中文视频模型的画面描述、镜头语言、风格和负面提示词。
- [ ] Given 用户选择目标视频模型，When 系统生成提示词，Then 每个镜头的提示词应使用对应模板。
- [ ] Given 模板类型无法识别，When 系统生成提示词，Then 系统应回退到通用模板并记录可排查的错误状态。

---

## 技术说明

- 模板应作为可维护配置或模块管理，为未来更多模板库预留扩展空间。
- MVP 不做复杂模板市场、模板投稿或在线模板同步。
- 需要覆盖正向提示词和负面提示词的基础结构。
- 具体提示词字段结构应与 TASK-003 的结构化分镜模型兼容。
