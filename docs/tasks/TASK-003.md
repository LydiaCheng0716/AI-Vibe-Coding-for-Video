## 任务描述

实现从故事文本和用户参数发起 LLM 分镜生成请求，并把返回结果解析为结构化分镜数据。系统应要求生成 3-10 个镜头，每个镜头包含概要、景别、运镜、时长建议和完整视频提示词字段。

---

## 验收标准

- [ ] Given 用户输入有效故事并完成必要设置，When 用户点击生成，Then 系统应向 LLM 发起分镜生成请求。
- [ ] Given LLM 返回有效结果，When 系统解析响应，Then 系统应得到 3-10 个结构化镜头。
- [ ] Given 任一镜头缺少概要、景别、运镜、时长建议或提示词，When 系统校验结果，Then 系统应将结果标记为无效并提示用户重试。
- [ ] Given LLM 请求失败，When 系统收到错误，Then 系统应展示可理解的失败信息并允许用户重试。
- [ ] Given 用户正在等待生成，When 请求未完成，Then 系统应展示加载状态并防止重复提交。

---

## 技术说明

- 生成结果必须使用结构化数据模型，避免只保存一大段自由文本。
- 该任务不要求实现模板多语言细节和人物一致性注入；这些由后续任务完成。
- 失败场景至少覆盖网络失败、鉴权失败、限流、返回格式异常。
- 不直接调用视频生成 API。
